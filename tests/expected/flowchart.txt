Flowchart

A decision flow with a branch, a join, and a back edge.

        ┌───────┐
        │ Start │
        └───────┘
            │
            │
            ▼
       /────────\
       │ Choice │◀──────┐
       \────────/       │
        yes │ no        │
       ┌────┴─────┐     │
       ▼          ▼     │
   ┌───────┐  ┌──────┐  │
   │ Do it │  │ Skip │  │
   └───────┘  └──────┘  │
       │          │     │
       └────┬─────┘     │
            ▼           │
         ┌─────┐        │
         │ End │────────┘
         └─────┘

Left-to-right with a long edge that skips a rank.

  
             ┌───┐
  ┌───┐   ┌─▶│ B │───┐  ┌───┐
  │ A │───┤  └───┘   ├─▶│ C │
  └───┘   │        skip └───┘
          └──────────┘

The flowchart-elk header is an alias (the ELK layout hint is ignored).

  
  ┌────┐    ┌─────┐
  │ In │───▶│ Out │
  └────┘    └─────┘
